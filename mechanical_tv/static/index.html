About this release

This optional upload studio runs entirely in simulation. The default HDMI service operates separately. Motor controls, encoder feedback, calibration, and browser shutdown are planned; they are not connected or implemented here.

All signed-in browsers share one player. In this first version, the most recent command wins. Use one operator at a time.

Use the installation guide for networking, service recovery, and safe Pi shutdown.
